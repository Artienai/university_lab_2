# Поиск тандемных повторов — проект на Python

Консольная программа для проверки слов и поиска тандемных повторов в тексте. Тандемный повтор — это слово, состоящее из двух одинаковых частей, например: `мама`, `тартар`, `abcabc`.

Проект написан на Python 3.10+. Для загрузки веб-страниц используется библиотека `requests`.

## Запуск в PyCharm

1. Склонируйте репозиторий или скачайте проект.
2. В PyCharm выберите **File → Open** и откройте папку `university_lab_2`.
3. Установите Python 3.10 или новее как интерпретатор проекта.
4. Установите зависимость:

   ```bash
   pip install -r requirements.txt
   ```

5. Откройте `main.py` и нажмите **Run**.

Запуск из терминала из корня проекта:

```bash
python main.py
```

Сервис поиска работает с текстом, не завися от того, откуда он получен. Источник текста можно заменить другой реализацией, не переписывая алгоритм поиска и консольное меню.

## Возможности программы

Программа предоставляет три режима:

1. Проверка одного введённого слова.
2. Поиск тандемных повторов в тексте, введённом пользователем.
3. Поиск тандемных повторов на веб-странице по URL.

Для веб-режима программа загружает страницу, извлекает текстовое содержимое и передаёт его сервису поиска. Ошибки некорректного URL, сетевого соединения и получения страницы обрабатываются отдельно.

## Регулярное выражение

Для поиска используется регулярное выражение:

```python
r"(?<!\\w)([^\\W\\d_]+)\\1(?!\\w)"
```

- `([^\\W\\d_]+)` — первая часть слова: одна или более букв.
- `\\1` — обратная ссылка на первую захваченную группу. Она требует, чтобы следующая часть полностью совпадала с первой.
- `(?<!\\w)` и `(?!\\w)` — проверки границ слова, чтобы не находить совпадение внутри более длинной последовательности букв, цифр или символов подчёркивания.

Таким образом, выражение находит слова, состоящие ровно из двух одинаковых буквенных частей, и поддерживает кириллицу и латиницу.

## Проверка тестов

Из корня проекта:

```bash
python -m unittest discover -s tests -v
```

В тестах проверяются положительные и отрицательные случаи, поиск в тексте, а также обработка ответов и ошибок веб-источника. Сетевые обращения в тестах подменяются, поэтому для запуска тестов доступ к интернету не требуется.
